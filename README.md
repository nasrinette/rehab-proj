# Guided Physiotherapy in Virtual Reality

A Unity-based prototype for asynchronous remote physiotherapy using immersive Virtual Reality (VR). This system enables doctors to create rehabilitation exercises, and patients to perform and receive visual/audio feedback, all within a shared but time-independent VR space.


[▶️ Demo Video](https://drive.google.com/file/d/1Zt6HFJFRJ545JL7IzBt8j2wgi664Akpe/view?usp=sharing)


---

## 🧠 Key Features

- 👩‍⚕️ **Doctor Mode**:  
  - Create and record new rehabilitation exercises  
  - Review patient submissions  
  - Annotate with 3D drawings and record audio feedback

- 🧍‍♂️ **Patient Mode**:  
  - Watch doctor-recorded exercises  
  - Perform and record own attempts  
  - View doctor’s feedback with timeline navigation

- ⏱️ **Asynchronous Workflow**:  
  Designed to allow doctors and patients to collaborate without needing to be online simultaneously.

- 🎮 **Intuitive VR Interface**:  
  Compatible with Meta Quest 2 using Meta XR SDK and XR Interaction Toolkit.

---

## 🛠️ Tech Stack

- Unity 2022.3 LTS
- XR Interaction Toolkit
- Meta XR SDK (Oculus Integration)
- Meta Avatars SDK for full-body tracking
- Tested on Meta Quest 2

## 🚀 Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/nasrinette/rehab-proj.git

2. Open the project in **Unity 2022.3.61f1 LTS**.
3. Connect a Meta Quest 2 via Oculus Link or build to device.
4. Press Play or build the app for Android.

Make sure Meta XR packages and XR Plugin Management are enabled. If needed, refer to:

* [Meta Avatars Documentation](https://developer.oculus.com/documentation/unity/meta-avatars/)
* [Unity XR Toolkit Guide](https://docs.unity3d.com/Packages/com.unity.xr.interaction.toolkit@2.0/manual/index.html)
